## 🧩 Problem Statement

You are given a **binary matrix** of size `m × n`.

🔄 You are allowed to **rearrange the columns in any order**.

🎯 Your goal is to find the **maximum area of a submatrix consisting entirely of `1's`** after performing the optimal column rearrangement.

---

## 💡 Key Idea

> Rearranging columns lets us **reshape the matrix smartly** to maximize contiguous `1's`.

## Approach

- Convert matrix into heights (histogram)
- For each row:
  - Sort heights in descending order (simulate column rearrangement)
  - Compute area = height × width

---

## Code (Java)

```java
class Solution {
    public int largestSubmatrix(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        int[][] height = new int[m][n];

        for (int j = 0; j < n; j++) {
            height[0][j] = matrix[0][j];
            for (int i = 1; i < m; i++) {
                if (matrix[i][j] == 0) height[i][j] = 0;
                else height[i][j] = height[i - 1][j] + 1;
            }
        }

        int maxArea = 0;

        for (int i = 0; i < m; i++) {
            int[] row = height[i].clone();
            java.util.Arrays.sort(row);

            for (int j = n - 1; j >= 0; j--) {
                int width = n - j;
                int area = row[j] * width;
                maxArea = Math.max(maxArea, area);
            }
        }

        return maxArea;
    }
}
```

## ⏱️ Complexity Analysis

- **Time Complexity:** `O(m × n log n)`  
  🔹 Sorting each row to simulate optimal column rearrangement  

- **Space Complexity:** `O(n)`  
  🔹 Extra space used for storing histogram heights per row
