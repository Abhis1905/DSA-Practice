# 1980. Find Unique Binary String

🔗 Problem Link  
https://leetcode.com/problems/find-unique-binary-string/

## Problem

We are given an array `nums` containing `n` unique binary strings.  
Each string has length `n`.

The task is to return **any binary string of length `n` that does not appear in the array**.

Since all strings are unique and there are only `n` of them, there must always be at least one binary string of length `n` that is missing.

---

## Idea

Instead of checking all `2^n` possible binary strings, we use a simple observation.

For each string in the array, we count how many `'1'` characters it contains.  
Then we record these counts using a **bitmask**.

Example:

```
string → number of 1s
001 → 1
101 → 2
111 → 3
```

We mark these counts in a bitmask.

After that, we find the smallest number of 1s that was not used by any string.

If i is that number, we construct a new string with:

i ones
n - i zeros

This guarantees the new string is different from all given strings.

Java Implementation
```java

class Solution {
    public String findDifferentBinaryString(String[] nums) {
        int mask = 0;

        for (var x : nums) {
            int cnt = 0;

            for (int i = 0; i < x.length(); ++i) {
                if (x.charAt(i) == '1') {
                    ++cnt;
                }
            }

            mask |= 1 << cnt;
        }

        for (int i = 0;; ++i) {
            if ((mask >> i & 1) == 0) {
                return "1".repeat(i) + "0".repeat(nums.length - i);
            }
        }
    }
}
```
Complexity

Time Complexity: O(n²)
We count the number of 1s for each string.

Space Complexity: O(1)
Only a bitmask variable is used.

Concepts Used

Bitmasking

Counting / frequency observation

Constructive approach
