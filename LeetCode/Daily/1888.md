# 1888. Minimum Number of Flips to Make the Binary String Alternating

🔗 Problem Link  
https://leetcode.com/problems/minimum-number-of-flips-to-make-the-binary-string-alternating/

## Problem

We are given a binary string `s`. We can perform two operations:

1. Move the first character of the string to the end.
2. Flip any character (`0 → 1` or `1 → 0`).

The goal is to find the **minimum number of flips** required to make the string **alternating**.

A string is alternating if no two adjacent characters are the same (for example: `0101`, `1010`).

---

## Idea

An alternating binary string can only look like one of these:

```
010101...
101010...
```

So the task is basically figuring out how many characters need to be flipped to match one of these patterns.

First, we compare the given string with the pattern `"0101..."` and count mismatches.  
If `cnt` characters differ, then:

- `cnt` flips are needed to match `"0101..."`
- `n - cnt` flips are needed to match `"1010..."`

So the answer for the current string is:

```
min(cnt, n - cnt)
```

But the problem also allows **rotating the string** (moving the first character to the end).  
Instead of actually rotating the string every time, we simulate it by adjusting the mismatch count as we move through the string.

For each possible rotation, we update the mismatch count and keep track of the minimum flips required.

---

## Java Implementation

```java
class Solution {
    public int minFlips(String s) {
        int n = s.length();
        String target = "01";
        int cnt = 0;

        for (int i = 0; i < n; ++i) {
            if (s.charAt(i) != target.charAt(i & 1)) {
                ++cnt;
            }
        }

        int ans = Math.min(cnt, n - cnt);

        for (int i = 0; i < n; ++i) {

            if (s.charAt(i) != target.charAt(i & 1)) {
                --cnt;
            }

            if (s.charAt(i) != target.charAt((i + n) & 1)) {
                ++cnt;
            }

            ans = Math.min(ans, Math.min(cnt, n - cnt));
        }

        return ans;
    }
}
```

---

## Complexity

**Time Complexity:** `O(n)`  
We traverse the string a couple of times.

**Space Complexity:** `O(1)`  
Only a few variables are used.

- Sliding window idea
